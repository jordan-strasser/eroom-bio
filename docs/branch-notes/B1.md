# B1 — biology re-canonicalized onto GO biological-process

## What this branch does

Biology nodes used to be identified by a hash of their free-text description
(`bio:<sha1>`), so two trials that phrased the same biology slightly differently
("renal vasodilation and natriuresis" vs "renal perfusion improvement and
natriuresis") became two separate nodes. The result: 71% of biology nodes were
singletons (seen in only one trial), so nothing learned about a piece of biology in
one trial could carry over to another.

This branch adds an alternative identity: each biology description is mapped to the
nearest **GO biological-process** term (via BioLORD similarity over a vocabulary of
2367 GO-BP terms drawn from the corpus's own genes), and the node is keyed by that
term (`bio:GO:xxxxxxx`). The same biology across trials now lands on one node —
exactly the way the mechanism layer already works with Reactome ids, which is the
densest, most-reused layer in the graph. Biology that doesn't map cleanly to a GO
term falls back to the old content hash, so no node is lost.

It is gated behind the environment flag **`EROOM_BIO_ONTOLOGY` (default OFF)**, so the
default build is byte-identical to before. Turn it on (optionally with
`EROOM_BIO_ONTOLOGY_GATE`, default 0.60) to get the GO-keyed biology.

## The honest result

It does what it was designed to do, and no more.

- **Reuse rises (the goal):** the fraction of biology nodes reused across ≥8 trials
  roughly **doubles, 4.6% → 8.8%**, and the singleton share drops 13 points
  (74% → 61%). The merges are biologically correct (e.g. "mitotic arrest" and
  "cell-cycle arrest" collapse onto *negative regulation of cell cycle*).

- **But prediction does not move:** the honest held-out AUROC is **0.567 → 0.569**, a
  statistical null. The reason is structural — the predictor reads *edge* beliefs, and
  merging biology *nodes* doesn't make the *edges* recur, because an edge's other
  endpoint (the mechanism or indication it connects to) is still diverse. Per-branch
  edge reuse stays essentially flat (efficacy 1.22 → 1.24).

- **It doesn't break anything:** the safety layer is untouched (within-target
  adverse-event spread 0.048, unchanged), and merging only mildly increases how often
  a node pools mixed outcomes (entropy +0.065) — a signal worth watching but not a
  regression.

**Takeaway:** B1 is a necessary *substrate* fix — it removes the paraphrase-driven
sparsity in the biology layer — but it is **not sufficient** on its own. Converting
that node-level reuse into the edge-level reuse the predictor actually uses requires
the next moves: context-conditioned hierarchical pooling (B2/B3) and more
reuse-dense data (Pillar C).
