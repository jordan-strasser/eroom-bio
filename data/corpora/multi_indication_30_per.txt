# Round-26 n=30-per-indication corpus.

# Target: 30 trials per holdout's primary indication, plus the 5 holdout
# NCTs at the bottom. Each indication section was curated to maximize
# chain-edge overlap with the corresponding holdout:
#   - same target class (target-level cross-trial learning)
#   - same mechanism (mechanism_affects density)
#   - same indication (biology_drives + responds_differently density)
#   - mix of successes AND failures (so the system can learn both
#     positive and negative outcomes for the chain)
#
# The 5 holdout NCTs at the bottom are FETCHED + POPULATED + ANNOTATED
# but EXCLUDED from attribution via --exclude-from-attribution.
# Their subgraphs land in the graph (chain prediction works), but their
# evidence doesn't fold into edge beliefs — true holdout, no
# self-attribution contamination.
