Round 8 — Conditioning architecture decision

eroom-bio · 2026-05-14 · design doc, no shipping · companion to audit/round_8_architecture_design.md

The question

Combo trials encode conditional dependence between constituents. Today's per-constituent chain decomposition treats each constituent's chain as independent. The trial's actual scientific finding — the arm-to-arm differential — has nowhere to live.

NCT00019682 (Schwartzentruber 2011): arm I (high-dose IL-2 alone) vs arm II (high-dose IL-2 + gp100 + montanide). The differential is evidence about gp100 given an IL-2 backbone. The graph today cannot represent "gp100 helped because the IL-2 backbone existed," only "gp100 helped in this trial" and "IL-2 helped in this trial" as two independent claims.

This is upstream of: the chain-picker question (scripts/inspect_trial.py:395, scripts/eval_predictions.py:118, src/annotation/attributor.py:611); Reactome biology per-constituent vs per-regimen; classifier per-arm vs per-hypothesis edge updates. All defer until this is settled.

v0.1.0 lock surface (CLAUDE.md)

Prediction math, trust-weight function (log-scaled, saturation at evidence_strength=49), edge priors, aggregation method, and edge topology are frozen at v0.1.0 until the corpus expands beyond melanoma. Round 8 is part of the lock-removal review.

Cross-indication transfer — ipi+nivo melanoma → ipi+nivo NSCLC

Today: melanoma's combo trial updates per-constituent edges (ipilimumab → CTLA4, nivolumab → PDCD1). NSCLC ipi+nivo trial inherits both via per-constituent compositional transfer.

Path 1: melanoma's combo trial updates ipilimumab+nivolumab → ???-target → … → melanoma. NSCLC trial's chain is rooted at the same regimen node, so its upstream edges transfer. But per-constituent CTLA4 → checkpoint_blockade doesn't get updated by the combo trial — it only sees evidence from the rarer mono-ipi trials. The compositional thesis breaks.

v0.1.0 lock surface — High

  • Edge topology semantically changes — chain backbones route through combo regimen nodes.
  • affects edge semantics: regimen → "primary target of regimen" is a new semantic.
  • The frozen mechanism (single chain backbone per (compound, target, mechanism, biology, indication)) loses one of its axes.

Pros / cons

Pros

  • Honest about what trials actually measure (arm outcomes).
  • Eval scoring well-defined per arm.
  • Backbone construction simpler (1 chain per cell).

Cons

  • Breaks compositional learning — the core thesis.
  • Combo regimen nodes are unique; weak Betas forever.
  • "Primary target of a regimen" is fuzzy.
  • Loses constituent-level connection to AE/efficacy.

Implementation cost

Chain rebuild rewrite ~50→~25 lines, plus a new regimen-target resolver (~100-200 lines, LLM or heuristic — both have problems). Attributor routing changes. Migration: re-populate every trial subgraph in oncology_annotated.json. ~5-10 new tests.

v0.1.0 lock surface — High (math signature change)

  • Math doesn't change shape (Beta-Binomial conjugate), but the retrieval signature gains a context-filter argument.
  • Trust-weight calculation: conditioned belief has fewer effective records → evidence_strength drops → trust drops. Correct, but changes prediction behavior; new tests needed.
  • Empty context_filter reproduces today's get_edge_belief exactly. Back-compat clean.

Pros / cons

Pros

  • Compositional learning preserved — chains stay per-constituent.
  • Conditioning is explicit and queryable.
  • Extends machinery that already exists (get_edge_belief_conditioned).
  • Generalizes beyond combos — line of therapy, biomarker status, prior treatment.

Cons

  • Sparsity nightmare — most conditional cells empty; predictions fall back to marginals constantly.
  • Combinatorial cells (gp100 | aldesleukin vs gp100 | aldesleukin + montanide vs …).
  • Smoothing rules between partitions need design.
  • Serialization redundancy (every record carries a dict).
  • Prediction API messier (caller must specify context).

Implementation cost

Generalize get_edge_belief_conditioned (~30 lines). Attributor co_compounds tagging (~20 lines). Path query threading (~30 lines + default decisions). ~15 new tests. Existing records have empty context → context-free behavior on retrieval → back-compat.

When predicting aldesleukin + gp100 + montanide → melanoma, the engine multiplies per-constituent path probabilities by the per-pair combination edge beliefs (geometric mean with trust weights). When predicting aldesleukin → melanoma alone, no combination edges are pulled in.

Cross-indication transfer — ipi+nivo melanoma → ipi+nivo NSCLC

Per-constituent chains preserved → per-constituent inheritance works as today. Plus: the ipilimumab ↔ nivolumab combination edge belief is updated by the melanoma trial and inherited by the NSCLC trial. "ipi+nivo synergy" learning transfers across indications, even without any NSCLC ipi+nivo trial having been observed. This is the architectural payoff.

Caveats

  • Indication-agnostic by default. Honest version: combination edges carry context["indication"] per record, so a later refinement (Path 2 mechanism applied to one edge type) can introduce conditioning — bounded scope, clear payoff.
  • Pairwise assumption. 3-way combos decompose into pairs; genuinely 3-way non-decomposable interactions can't be represented. Pairwise is the floor above "no representation."
  • Symmetry convention. Store one direction by lex order; prediction code reads symmetrically.

v0.1.0 lock surface — Medium

  • New edge type added; existing edges keep their semantics.
  • Aggregation method (trust-weighted geomean) unchanged.
  • Edge topology technically perturbed, but the perturbation is additive (new edge type) rather than rewriting any existing edge's behavior.

Pros / cons

Pros

  • Compositional learning preserved (per-constituent chains untouched).
  • Combo evidence has a natural, queryable home.
  • Combination edges themselves transfer across indications.
  • Smallest v0.1.0 lock surface — one new edge type, no math change.
  • Aggregation reuses existing trust-weighted geomean.

Cons

  • Pairwise assumption — 3-way interactions can't be expressed natively.
  • Combination edges are sparse, but bounded: O(C²) pairs, not combinatorial cells.
  • Indication-conditioning is a separate open question.
  • Symmetry convention needed.

Implementation cost

Enum + direction helper (~10 lines). Attributor arm-differential emission (~80-120 lines). Attributor single-arm-combo weaker emission (~30 lines). Path query inclusion (~30 lines). ~10-15 new tests. No migration required — existing trial subgraphs have no combination edges and predictions stay valid; retro-fit pass on cached classifications is optional.

Decision

Path 3 — explicit combination edges

One new edge type (MODULATES_EFFICACY_OF), no math change, no signature change to predict_clinical_hypothesis. Preserves the compositional thesis. Lets combo learning itself transfer across indications.

Reasoning

  1. Compositional thesis preserved. CLAUDE.md frames the goal as "decompose trial outcomes into mechanistic causal-chain updates" and produce "interpretable, compositional predictions." Path 1 sacrifices this. Path 2 nominally preserves it but sparsity makes the conditioned beliefs mostly empty — in practice it looks like Path 1 without admitting it.
  2. Smallest v0.1.0 lock perturbation. Adding an edge type is the most surgical change available. Paths 1 and 2 each touch the math or the chain-construction loop.
  3. Cross-indication transfer of combo learning is the architectural payoff. Path 3 makes "ipi+nivo synergy" first-class graph state that transfers across indications. Path 1 can't — regimen nodes are unique and don't inherit. Path 2 can't in practice — conditioned cells rarely fire.
  4. Bounded sparsity. Combination edges scale O(C²) in compounds, not combinatorial in context cells. At 100 compounds, ≤ 10,000 possible pairs; at the corpus's actual repeat rate, hundreds will see evidence within a few thousand trials.
  5. Faithful to feedback_simple_faithful. The simplest change that serves the thesis. Adding an edge type is simpler than changing the math.

Honest caveats (known followups, not blockers)

  • Pairwise restriction. Acceptable now — every existing combo trial in the slice is decomposable into pairs.
  • Indication-conditioning of combination edges deferred. v1 is indication-agnostic with context["indication"] tagged on each evidence record so a later refinement can introduce conditioning. This is the right place for Path 2's mechanism to land — bounded scope, clear payoff.
  • Symmetry. Store one direction by lex order; prediction code reads symmetrically.
